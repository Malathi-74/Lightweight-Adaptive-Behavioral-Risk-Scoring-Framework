# Lightweight-Adaptive-Behavioral-Risk-Scoring-Framework
This project is a web-based behavioral authentication system that enhances login security by analyzing user behavior, such as typing speed, mouse movements, and session activity. The system calculates a risk score during login and provides additional verification, such as OTP, when suspicious behavior is detected.
## Tech Stack

- HTML
- CSS
- JavaScript
- Python
- Flask
- MongoDB

 ## Features

- User Registration
- User Login
- Behavioral Authentication
- Risk Score Analysis
- OTP Verification
- Product Management
- Shopping Cart
- Secure Checkout
- Admin Dashboard
- User Activity Monitoring
